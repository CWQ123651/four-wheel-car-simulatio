# 四轮小车控制模拟
标准C语言实现的小车控制仿真程序，无第三方依赖，支持标准输入重定向运行。

## 功能概述
模拟四轮小车的控制系统，支持自动控制与手动控制两种模式，手动控制优先级更高。
程序接收文本命令，维护系统状态、控制请求、目标速度与车轮实际速度，支持步进调速、急停、复位等操作。

## 编译
### GCC 编译（推荐，符合题目标准C要求）
```bash
make
```

编译完成后生成可执行文件 `car`。

清理编译产物：

```
make clean
```

### Visual Studio 编译

1. 将所有 `.c` 文件加入项目源文件
2. 项目属性 → C/C++ → 常规 → 附加包含目录，添加 `include` 文件夹
3. 直接编译运行即可

## 运行

### 交互式运行

```
./car
```

启动后手动逐行输入命令，按回车执行。

### 文件重定向运行（自动测试标准方式）

```
./car < test.txt
```

程序自动按顺序执行 `test.txt` 中的所有命令，输出对应结果。

## 支持命令

表格

| 命令 | 功能说明 |
| --- | --- |
| `start` | 从待机状态进入运行状态 |
| `forward\|backward\|left\|right <speed>` | 设置自动控制及速度 |
| `auto stop` | 设置自动控制为停止 |
| `manual forward\|backward\|left\|right <speed>` | 设置手动控制及速度（优先级高于自动） |
| `manual stop` | 设置手动控制为停止 |
| `manual release` | 释放手动控制，恢复自动控制 |
| `step` | 车轮实际速度向目标步进一次（单轮最大变化 20） |
| `emergency` | 立即急停，车轮实际速度直接清零 |
| `reset` | 系统复位到待机状态，清空所有控制请求 |
| `status` | 输出当前完整状态（严格 6 行格式） |
| `quit` | 退出程序 |

## 约束规则

- 速度参数范围：`0 ~ 100`，超出范围的命令将被忽略
- 只有`RUNNING`运行状态下，运动类命令才会生效
- 手动控制优先级高于自动控制
- 每次执行 `step`，单轮速度最大变化量为 20
- `emergency` 急停不经过 step，立即清零实际速度
- 未知命令、参数缺失、非法输入不会导致程序崩溃
